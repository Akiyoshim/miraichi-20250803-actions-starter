# Resendの設定

Resendは、プログラムからメールを送るためのサービスです。このリポジトリでは、要約結果をあなた宛てのメールとして送るために使います。

## 基本の考え方

1. Resendにサインアップする（GitHubアカウントでログイン可）
2. APIキーを作る
3. **送信元アドレス**（`EMAIL_FROM`）と**送信先アドレス**（`EMAIL_TO`）を決める

送信元アドレスには2つの選び方があります。

## テスト用アドレスで始める（今日はこれでOK）

独自ドメインを持っていなくても、Resendが用意している `onboarding@resend.dev` を送信元として使えます。

```text
EMAIL_FROM = onboarding@resend.dev
EMAIL_TO   = 自分の受信したいメールアドレス
```

このリポジトリのセットアップは、この方法を前提にしています。**独自ドメインの検証は任意です。**

## 独自ドメインを使う（発展・任意）

自分が持っているドメイン（例: `example.com`）から送りたい場合は、Resendの管理画面でドメインを追加し、指示されたDNSレコード（SPF/DKIM）を登録して検証します。検証には数分〜数時間かかることがあります。

独自ドメインを使うメリット:

- 送信元アドレスを自分の好きなものにできる（例: `digest@example.com`）
- 迷惑メール判定されにくくなることがある

今日のハンズオンでは扱いません。興味があれば、[Resendの公式ドキュメント](https://resend.com/docs)を参照してください。

## 送信先について

`EMAIL_TO` には自分が受け取りたいメールアドレスを入れます。テスト用アドレス（`onboarding@resend.dev`）を送信元にする場合、Resendのアカウントに登録したメールアドレス宛てであれば送信できます。

## 無料枠について

小規模な個人利用であれば、Resendの無料枠で始めやすい構成です。ただし送信件数などに上限があります。「完全無料」ではありません。最新の条件は [Resendの料金ページ](https://resend.com/pricing) を確認してください。
